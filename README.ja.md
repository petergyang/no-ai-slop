# No AI slop

[English](README.md) · [简体中文](README.zh-CN.md) · 日本語

このスキルは、文章から 20 種類以上の AI slop パターンを取り除き、AI slop の検出にも役立ちます。

## 検出できるもの

検出するパターンには、次のようなものがあります。

| パターン | ありがちな表現 |
|---------|-------------|
| 二項対立 | 「X ではない。Y だ。」 |
| 前置きだけの書き出し | 「要するに……」 |
| 洞察を装う導入 | 「誰も教えてくれないのは……」 |
| コロンによる大げさな提示 | 「最大の利点：学習すること。」 |
| 表面的な分析 | 「……チームの取り組みを示している」 |
| 重要性の誇張 | 「極めて重要な節目となる」 |
| 曖昧な情報源 | 「専門家の意見は一致している」、「研究によれば」 |
| 強そうに見せる動詞 | 「一元管理のハブとして機能する」 |
| 同義語の言い換え回し | agent、assistant、tool と呼び方を次々に変える |
| 否定の列挙 | 「X ではない。Y でもない。Z だ。」 |
| ドラマチックな短文分割 | 「それだけ。話はそれで終わり。」 |

また、良い文章を書くための基本も徹底します。効果的な場合は要点から始め、能動態を使い、分かりにくい文を整理し、抽象表現より具体的な数字を優先します。

## 使い方

**1. 下書きを編集する。** 下書きを貼り付けてスキルを呼び出します。

```
/no-ai-slop

[your draft]
```

編集済みの下書きと、短い What changed（変更点）セクションが返されます。このスキルは必要最小限で効果的な編集を行い、その後 [eval.md](eval.md) に照らして自分の作業を確認します。

**2. AI slop を検出する。** 文章が AI らしく読めるかどうかを尋ねます。

```
/no-ai-slop is this AI slop?

[the text]
```

検出したすべてのパターンと、それぞれに該当する原文が返されます。

## ファイル

1. `SKILL.md`：編集ルールとワークフロー。
2. `eval.md`：スキルが自分の編集結果に対して実行する合格・不合格チェック。
